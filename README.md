# CPPG 매일 학습 수정본

개인정보보호법을 매일 5분 동안 읽고, 2~3문제를 풀고, 암기카드를 뒤집는 학습 페이지입니다. 기존의 단순 정적 화면을 유지하면서 세 섹션을 독립적으로 새로고침할 수 있도록 확장했습니다.

## 주요 변경 사항

오늘의 조문은 첫 화면 로드와 새로고침 때마다 현행 법령 API를 먼저 조회한 뒤 2~3개를 새롭게 추출합니다. API가 일시적으로 실패하면 저장 데이터로 자동 전환하며, 이전 조문 묶음과 같은 조합이 연속으로 나오지 않도록 처리했습니다. 중요 조문에는 `★ 시험 빈출` 표시를 보여줍니다. 조문마다 핵심 한 줄 요약과 태그를 함께 표시하며, 카드 아래의 새로고침 버튼은 오늘 조문만 다시 선정합니다.

관련 기출형 문제는 오늘 선정된 모든 조문을 문맥으로 사용해 2~3개의 4지선다 문제를 생성합니다. 문제를 누르면 즉시 정답·오답과 해설을 보여줍니다. AI 생성이 실패하거나 API 키가 없을 때도 조문 기반 기본 문제를 제공하도록 fallback을 넣었습니다.

암기카드는 오늘 조문과 연결된 카드만 2~4장 골라 보여주며, 클릭 시 질문과 정답이 뒤집힙니다. 상단에는 불필요한 연속 학습일이나 루틴 진행 박스를 두지 않고, 조문·문제·카드 학습에 바로 집중하도록 구성했습니다.

## 현행 법령 연동

`api/law.js`는 국가법령정보센터의 현행법령 본문 API를 서버에서 호출하도록 구성했습니다. 공식 안내상 본문 조회 API는 `target=eflaw`, `type=JSON`, `ID` 또는 `MST`와 `OC` 인증값을 사용합니다. 이 수정본은 개인정보 보호법 법령 ID `011357`을 사용하고, 실제 JSON 응답의 `법령.조문.조문단위` 배열에서 `조문여부=조문`인 항목만 추출합니다. CDATA 잔여 문자열과 HTML 태그도 정리합니다.

Vercel 프로젝트 환경변수에 다음 값을 추가해야 실시간 동기화가 활성화됩니다.

```text
LAW_API_OC=발급받은 국가법령정보센터 Open API 인증값
GEMINI_API_KEY=Google Gemini API 키
GEMINI_MODEL=gemini-2.5-flash
```

`LAW_API_OC`가 없으면 저장된 `data.json`으로 동작하고 화면에 해당 상태를 표시합니다. `GEMINI_API_KEY`가 없거나 AI 호출에 실패하면 내부 가중치와 fallback 문제를 사용하므로 학습 화면이 빈 상태가 되지 않습니다. API 키는 브라우저 코드에 넣지 않고 서버리스 함수 환경변수에만 저장해야 합니다.

## 실행

정적 미리보기는 다음처럼 실행할 수 있습니다.

```bash
python3 -m http.server 4173
```

실시간 법령과 AI API까지 사용하려면 Vercel에 저장소를 연결하고 `api/` 폴더가 서버리스 함수로 배포되도록 한 뒤 환경변수를 설정합니다. 별도 빌드 단계가 없는 순수 HTML/CSS/JavaScript 프로젝트입니다.

## 학습 UX 추천

매일 부담을 낮추려면 첫 화면에서 해야 할 일을 세 단계로 고정하고, 각 단계의 예상 시간을 짧게 보여주는 현재 구조가 적합합니다. 조문을 많이 보여주기보다 2~3개만 유지하고, 문제는 처음부터 준비해 두되 새 문제 버튼으로 교체할 수 있게 하는 것이 좋습니다.

게임화는 큰 랭킹보다 개인 기록 중심으로 운영하는 편이 안전합니다. 연속 학습일, 오늘의 3단계 완료율, 이번 주 학습 조문 수 정도만 표시하면 성취감은 주되 실패 부담은 줄일 수 있습니다. 향후에는 오답 조문을 다음 날 우선 노출하고, 카드에서 두 번 연속 맞힌 항목의 노출 빈도를 낮추는 간단한 간격 반복을 추가하는 것을 권장합니다.

> 법령 본문과 AI가 생성한 문제는 시험 학습 참고용으로 사용하고, 실제 법률 판단은 반드시 국가법령정보센터의 최신 원문을 확인해야 합니다.
